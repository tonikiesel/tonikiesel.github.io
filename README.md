# toni-kiesel-fisi.dev

Meine persönliche Bewerbungs- und Profilseite als angehender Fachinformatiker für Systemintegration.

🌐 **Live:** [toni-kiesel-fisi.dev](https://toni-kiesel-fisi.dev)

## Worum es geht

Die Seite stellt mich, meinen Werdegang vom Bäckerhandwerk in die IT und meine Kenntnisse vor. Sie richtet sich an Unternehmen im Raum Zwickau, die ab September 2027 einen Praktikumsplatz für sechs Monate anbieten können.

## Technik & Infrastruktur

| Bereich | Umsetzung |
|---|---|
| Hosting | GitHub Pages mit HTTPS |
| Domain & DNS | Eigene Domain bei IONOS, DNS-Einträge selbst eingerichtet |
| Versionsverwaltung | Git / GitHub |
| Kontaktformular | Formspree (leitet Nachrichten per E-Mail weiter) |
| Frontend | HTML, CSS und JavaScript ohne Frameworks |

## Funktionen

- Responsives Layout für Handy, Tablet und Desktop
- Einstellungsmenü (Zahnrad): helles Design, Animationen aus, Farbmodus für Blau-Gelb-Sehschwäche (Tritanopie) und „Direkt zum Profil“
- Die Einstellungen werden nur lokal im Browser gespeichert (Local Storage)
- Keine Cookies, keine Tracking- oder Analysedienste
- Schrift und Bilder werden direkt von der eigenen Domain geladen, nicht von Drittanbietern

## Aufbau

```
├── index.html        Inhalt und Struktur der Seite
├── style.css         Gestaltung und Layout
├── script.js         Interaktive Funktionen
├── montserrat.woff2  Schriftart (lokal eingebunden)
├── toni.jpg          Profilfoto
└── CNAME             Verknüpfung mit der eigenen Domain
```

## Was ich dabei gelernt habe

Domain, DNS und Hosting habe ich selbst eingerichtet. Den Code habe ich mit KI-Unterstützung entwickelt und dabei viel über HTML, CSS und JavaScript gelernt: wie eine Seite aufgebaut ist, wie Layouts auf verschiedenen Bildschirmgrößen funktionieren und wie man Änderungen mit Git sauber verwaltet.
